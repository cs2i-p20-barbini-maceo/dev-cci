# Dans quel cadre s'appliquent-ils ?

## C'est quoi GitHub, déjà ?

Avant de parler des workflows, il faut comprendre où ils vivent.

**GitHub** est une plateforme en ligne où les développeurs stockent leur code. C'est un peu comme Google Drive, mais pour du code informatique. Quand tu travailles sur un projet, ton code est sauvegardé sur GitHub.


## Dans quel contexte ?

Les workflows GitHub s'appliquent dans le **développement logiciel** dès qu'on utilise Git et GitHub pour gérer son code. Ça concerne :

- Un développeur seul sur un projet personnel
- Une équipe de plusieurs personnes qui travaillent ensemble
- Une entreprise qui met à jour son application régulièrement

Plus un projet évolue souvent, plus les workflows sont utiles.
