# À quoi servent-ils ?

Un workflow, c'est comme un **assistant robot** qui fait des tâches à ta place, automatiquement, sans que tu aies à y penser.

## Les utilisations les plus courantes

### Tester le code automatiquement

Quand tu modifies ton code, le workflow peut lancer des **tests** pour vérifier que tout fonctionne encore. Si quelque chose est cassé, tu es prévenu tout de suite avant que ça parte en production.

### Publier un site automatiquement

Dès que tu pousses du code sur GitHub, le workflow peut construire et déployer ton site sur internet.

### Vérifier la qualité du code

Un workflow peut analyser ton code pour détecter les mauvaises pratiques, les fautes de style, ou les oublis.
