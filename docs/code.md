# Code

## Code en ligne

Le code en ligne s'obtient en entourant le texte par des backticks `` ` ``.

=== "Exemple"

    ```markdown
    La commande `git status` affiche l'état du dépôt.
    ```

=== "Résultat"

    La commande `git status` affiche l'état du dépôt.

## Bloc de code

Un bloc de code s'obtient en entourant le code par trois backticks ` ``` `.

=== "Exemple"

    ````markdown
    ```python
    def hello(name):
        print(f"Hello, {name}!")

    hello("Markdown")
    ```
    ````

=== "Résultat"

    ```python
    def hello(name):
        print(f"Hello, {name}!")

    hello("Markdown")
    ```
